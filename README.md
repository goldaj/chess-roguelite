# ChessRoguelite

Version améliorée (assets lisibles type chess.com, shop aléatoire 3 choix, plateau initial 8x3, coordonnées, UI boutons + animations).

## Prérequis
- Python 3.10+
- `pip install pygame pillow`

## Lancer
```
python -m src.main
```
ou
```
python src/main.py
```

Tout se pilote **à la souris** (boutons).
